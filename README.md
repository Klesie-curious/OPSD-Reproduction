# OPSD-Reproduction
Reproduction and experimental analysis of On-Policy Self-Distillation for Large Language Models.

## 1. Paper

- **Title:** Self-Distilled Reasoner: On-Policy Self-Distillation for Large Language Models
- **Original Repository:** https://github.com/siyan-zhao/OPSD
- **Paper:** https://arxiv.org/abs/2601.18734

## 2. Project Goals

This project aims to reproduce the main experiments of OPSD and understand its training mechanism.

The primary objectives are:

- Reproduce OPSD training on Qwen3-1.7B.
- Evaluate performance on AIME24, AIME25, and HMMT25.
- Compare experimental results with the paper.
- Investigate implementation details and reproducibility challenges.
